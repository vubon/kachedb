## Reporting a Vulnerability

We take the security of KacheDB seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Report the vulnerability privately via [GitHub Security Advisories](https://github.com/vubon/kachedb/security/advisories/new) or by emailing the project maintainers directly at [vubon.roy@gmail.com](mailto:vubon.roy@gmail.com).
3. Include detailed steps to reproduce the issue, proof-of-concept code, and the affected version/architecture.

### Response Commitment
- **Initial Response:** Within 24 hours.
- **Triage & Fix Window:** Critical vulnerabilities will be prioritized for immediate hotfix within 72 hours.
- **Credit:** We will publicly acknowledge your responsible disclosure in our release notes (unless you prefer anonymity).
